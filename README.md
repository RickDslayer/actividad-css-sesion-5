# Actividad CSS - Sesión 5

Ejercicio práctico de CSS enfocado en estilizado de componentes de interfaz: botones, enlaces, tarjetas de perfil y listas de habilidades.

## Contenido

- `css sesion 5/index.html` y `index2.html`: páginas de ejemplo con distintos componentes (botón, tarjeta de perfil, lista de skills).
- `css sesion 5/css/styles.css` y `sytles2.css`: hojas de estilo con las clases utilizadas (`button`, `profile-card`, `skills`, entre otras).

## Cómo verlo

Abre `css sesion 5/index.html` en el navegador directamente, sin necesidad de un servidor.

## Tecnologías

- HTML5
- CSS3
